# Fonts

`Wittgenstein.ttf` is the variable font of google/fonts (`ofl/wittgenstein/Wittgenstein[wght].ttf`). Klassik sets page titles and section headings in it at weight 500 ([ADR 0030](../../docs/adr/0030-type-and-spacing.md)). The full file keeps the OpenType figures that the web files drop.

The font is licensed under the SIL Open Font License 1.1. `OFL.txt` holds the licence and the copyright. The app bundles the font with this licence.

The app needs one weight only. `Klassik/Fonts/Wittgenstein-Medium.ttf` is the static weight 500 of the upstream repository (`pages/ttf/Wittgenstein-Medium.ttf` in jrgdrs/Wittgenstein), with the same licence beside it.
