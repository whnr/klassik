# 0063. Chronology uses a plain works drawer

Date: 2026-11-19. Decided by Flo in the 0.15.0 feedback. Bead: sz-kaqj.2.
Replaces the sheet list rule of [0030](0030-type-and-spacing.md) for the Chronology works drawer.

## Context

The counted works drawer shows library content. Flo expects the normal works list there.

## Decision

- The drawer uses plain works rows, without inset grouped backgrounds.
- The drawer keeps Klassik's page ground at every detent, including full height.

## Consequences

Other sheets keep their existing list style.
