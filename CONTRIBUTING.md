# Contributing

Klassik has strong opinions. Read the README first.

- Open an issue before you start a feature. Agree on it first.
- Small fixes are welcome without an issue.
- Use only OpenSubsonic standard fields. No server-specific features.
- Tell us if you used AI to write the change.
- Understand your change without an AI explaining it to you.
- Start the pull request description with one paragraph that you write yourself, not an AI: why, the risk, and where reviewers must look.
- Follow the writing rules in [AGENTS.md](AGENTS.md#writing) for comments and commit messages.
