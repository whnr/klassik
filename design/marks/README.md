# Marks

`fermata.svg` is the favourite mark of [ADR 0033](../../docs/adr/0033-engraved-fermata.md): an engraved arc over a dot, Klassik's own drawing. It is the master for the custom SF Symbol. The view box is the 17 × 10.5 grid of the ADR; the feet sit on its bottom edge, the baseline. The path fills with `currentColor`, so the colour comes from the favourite or favourite-off token.
